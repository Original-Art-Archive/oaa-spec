# Invalid Examples

This directory is reserved for intentionally invalid examples used by future validators and conformance tests.

## Planned Cases

- `missing-manifest/`: archive content without a required manifest.
- `bad-image-path/`: manifest references unsafe or missing artwork file paths.
- `unsupported-version/`: manifest declares an unsupported format version.
